# Stenstadens Entreprenad

19 färdiga HTML-sidor med lokala bilder, originalets logotyp och typsnitt.

Packa upp ZIP-filen och lägg mappens innehåll i repots rot. Aktivera GitHub Pages från huvudgrenen och rotmappen. Ingen byggprocess behövs.

Heron visar en inspirationsbild av Phil Hearing från Unsplash: https://unsplash.com/photos/AqhPku3KErM. Den föreställer inte företagets eget projekt. Snöröjningsfordonet visas i snöröjningsdelen. Bilder och kundomdömen är hämtade från företagets befintliga webbplats. Omdömena är korta utdrag, inte verifierade Google-recensioner eller ett samlat betyg.

Kontaktformuläret öppnar besökarens e-postprogram med ett utkast som besökaren själv skickar.

Utseende: style.css. Interaktioner: script.js. Innehåll: respektive HTML-fil. Typsnittets licens finns i assets/FONT-LICENSE.txt.
